Detailed Description

Handles camera operations including ROI sharpness monitoring, focus search, and depth mapping.

This class integrates with the System object to manage camera functionalities such as setting ROI, performing focus searches, and generating depth maps. It also provides thread-safe methods for monitoring and updating camera parameters.
