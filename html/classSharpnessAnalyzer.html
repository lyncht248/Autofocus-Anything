Detailed Description

Analyzes the sharpness of image frames by computing horizontal sharpness profiles.

The SharpnessAnalyzer class provides methods to analyze image frames and compute sharpness values for horizontal segments. It supports both OpenCV Mat objects and raw data pointers.
