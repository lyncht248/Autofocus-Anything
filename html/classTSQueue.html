Detailed Description

template<class T>
class TSQueue< T >

A thread-safe queue with optional size limit.

This class provides a thread-safe queue implementation using Glib::Threads::Mutex and Glib::Threads::Cond for synchronization. It supports operations like push, pop, clear, and waiting for the queue to become empty.

Template Parameters
TThe type of elements stored in the queue.
