Detailed Description

Namespace for SDL window-related functionality.

Provides functions for managing SDL windows and rendering operations.

The SDLWindow namespace includes functions and variables for managing SDL windows and rendering operations in a child process.

The SDLWindow namespace includes functions for creating, managing, and rendering SDL windows, as well as handling depth map data and user interactions.
