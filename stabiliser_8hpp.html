Detailed Description

Declares the Stabiliser class and related structures for frame stabilization.

This file provides the declaration of the Stabiliser class, which includes methods for stabilizing frames, creating vessel maps, and analyzing vessel structures. It also defines supporting structures such as Chain, compit, and AbsPixel for vessel tracking and visualization.
